# Second Page

A multi-section landing page built as a follow-up to my first Odin Project landing page, with a different design and more layout practice.

## Live preview
https://scropico2.github.io/Second-page/

## What's on the page

- **Navigation bar:** logo box on the left, links (About, Contact Us, Information, Mail) and a "Sign Up" button on the right
- **Introduction section:** heading banner, intro text, a "Click here!" button and a featured photo
- **Cards section:** four image cards in a row, each with a caption
- **Testimonial:** a quote with the author's name and a round profile photo
- **Call to action:** a centered box with a limited-offer message and a Register button
- **Footer:** copyright line
- **Extra pages:** About, Contact Us, Information and Mail

## What I practiced

- Page layout with Flexbox (rows, columns, centering, spacing with `gap`)
- Centering boxes with `max-width` and `margin: auto`
- Reusing colors with CSS variables (`--bg`, `--surface`, `--text`, `--muted`)
- Styling images with `object-fit` and rounded corners (`border-radius`)
- Linking several HTML pages together
- Using Git and GitHub to commit, merge and push a project
